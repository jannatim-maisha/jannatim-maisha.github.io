# jannatim-maisha.github.io

Source of my academic website: **https://jannatim-maisha.github.io**

Research, publications, projects, teaching, experience and CV. Built with
[Jekyll](https://jekyllrb.com/) using the [Academic Pages](https://academicpages.github.io/)
template and served by GitHub Pages.

## Edit

| What | Where |
|---|---|
| Home / about | `_pages/about.md` |
| Research & publications | `_pages/research.md` |
| Projects | `_pages/projects.md` |
| Education, teaching, experience, CV | `_pages/education.md`, `teaching.md`, `experience.md`, `cv.md` |
| Menu | `_data/navigation.yml` |
| Name, bio, sidebar links | `_config.yml` |
| PDFs (certificates, CV, thesis) | `files/` |

## Preview locally

```sh
bundle install
bundle exec jekyll serve -l -H localhost   # http://localhost:4000
```
